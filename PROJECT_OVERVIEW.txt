API ENDPOINTS (12 Total):
════════════════════════════════════════════════════════════════════════════════

Organizations:
  POST /api/orgs              → Create org
  GET  /api/orgs/:org_id      → Get org

Agents:
  POST /api/agents            → Hire agent
  GET  /api/agents/:org_id    → List agents

Simulations:
  POST /api/simulations       → Run simulation
  GET  /api/simulations       → List simulations

Deployments:
  POST /api/deployments       → Deploy agent
  GET  /api/deployments       → List deployments

Governor:
  POST /api/governor          → Create rules
  GET  /api/governor          → Get rules

Analytics:
  GET  /api/analytics         → Get metrics

Health:
  GET  /api/health            → Health check


DATABASE SCHEMA (7 Tables):
════════════════════════════════════════════════════════════════════════════════

organizations
  ├── id (PRIMARY KEY)
  ├── name
  └── created_at

users
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
  ├── email (UNIQUE)
  ├── name
  ├── role (owner|manager|viewer)
  └── created_at

agents
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
  ├── name
  ├── role
  ├── description
  ├── tools (JSON)
  ├── cost_per_task
  ├── status (active|inactive)
  └── created_at

simulations
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
  ├── agent_id (FOREIGN KEY)
  ├── status
  ├── accuracy
  ├── cost
  ├── latency
  ├── failure_rate
  └── created_at

deployments
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
  ├── agent_id (FOREIGN KEY)
  ├── environment (email|api|slack)
  ├── status (active|paused|rollback)
  ├── version
  └── created_at

tasks
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
  ├── deployment_id (FOREIGN KEY)
  ├── input
  ├── output
  ├── cost
  ├── status
  └── created_at

governor_rules
  ├── id (PRIMARY KEY)
  ├── org_id (FOREIGN KEY)
