  → Check Render backend logs
  → Verify environment variables are set
  → Try restarting the service

"Deployment still building"
  → This takes 5-10 minutes, be patient
  → Check status in Vercel/Render dashboard

"Need to restart"
  → Delete and start over (code is safe on GitHub)
  → Takes 60 minutes again
